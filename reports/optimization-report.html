TPFanCtrl2 Optimization Report

Generated: 2026-05-12

The main ThermalManager optimization work is implemented. The EC retry simplification still needs validation on real ThinkPad hardware before it should be treated as fully proven.

Implemented

  • ThermalManager caches hot-path config values in CachedConfig.
  • UpdateConfig marks cached values stale through an atomic flag.
  • WorkerLoop refreshes cached config when needed.
  • UpdateSensors now performs one sensor/fan sample and one retry after 50 ms.

Risks

  • The previous retry behavior may have masked flaky EC timing on specific models.
  • Tests cover basic operation, but do not fully model intermittent EC communication failures.
  • Future changes should preserve the invariant that cached config is refreshed from the worker thread.

Validation

  • Run xmake run logic_test and xmake run core_test.
  • Exercise cold boot, resume from sleep, BIOS, manual, smart, PID, and rapid setting changes on target hardware.
  • Compare EC read-failure logs before and after the retry simplification.
