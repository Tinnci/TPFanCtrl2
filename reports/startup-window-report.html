TPFanCtrl2 Startup Window Report

Generated: 2026-05-12

The GUI executable could show a command line window when built in debug mode because the GUI target selected the console subsystem outside release builds.

Resolution

The TPFanCtrl2 target now always links as a Windows subsystem binary while preserving the existing main entry point through mainCRTStartup.

  • MSVC: /SUBSYSTEM:WINDOWS /ENTRY:mainCRTStartup
  • Clang/Zig: -Wl,/SUBSYSTEM:WINDOWS -Wl,/ENTRY:mainCRTStartup

Unchanged

  • logic_test and core_test keep console output.
  • Application logs still use the existing logging path.
