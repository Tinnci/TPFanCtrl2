TPFanCtrl2 Project Report

Generated: 2026-05-12

TPFanCtrl2 is a Windows 10/11 ThinkPad fan-control utility using C++20, ImGui, Vulkan, xmake, GoogleTest, and the legacy TVicPort driver for EC I/O.

Build Model

  • x86 is the default architecture because TVicPort is 32-bit only.
  • The GUI target outputs to artifacts/bin/app.
  • Test targets output to artifacts/bin/tests.
  • Release builds enable fast optimization, symbol stripping, LTCG/LTO, and SSE2.

Runtime Constraints

  • Administrator privileges are required for low-level EC access.
  • TVicPort can be blocked by Windows security features such as HVCI/Core Isolation.
  • The project remains Windows-only because it depends on Win32, Vulkan Win32 surfaces, and TVicPort.
